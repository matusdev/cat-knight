# Материалы для App Store и Google Play

| Файл | Что это |
|---|---|
| `screens/ios/` | 8 кадров × RU/EN, 1290×2796 — iPhone 6,7″/6,9″ (App Store берёт их и для меньших iPhone) |
| `screens/play/` | 8 кадров × RU/EN, 1080×1920 — телефоны Google Play; `feature-*.png` — графика для витрины 1024×500 |
| `screens/raw/` | исходные снимки игры без подписей (1170×2532) — для сайта, соцсетей, пресс-кита |
| `listing-ru.md`, `listing-en.md` | название, подзаголовок, ключевые слова, краткое и полное описание, подсказки к возрастному рейтингу |
| `privacy.html` | политика конфиденциальности RU+EN — разместить по публичной ссылке, заполнить [в скобках] |
| `storyboard.md` | раскадровка видео-превью на 30 с с командами для съёмки сцен |
| `shots.cjs` | генератор кадров: `node store/shots.cjs` из `_not_main` (все сцены, ~10 мин), `node store/shots.cjs boss,map` — выборочно, `--compose` — только пересобрать подписи |

Подписи кадров — в `shots.cjs` (массив `SCENES`), шрифт Nunito, кегль подбирается сам под ширину.

## Чек-лист публикации

**Обе платформы**
- [ ] Аккаунты: Apple Developer ($99/год), Google Play Console ($25 один раз)
- [ ] Идентификатор приложения в `mobile/app.json` вместо `com.example.catknight`
- [ ] Политика конфиденциальности по публичной ссылке, заполнены [имя], [почта], [сервис аналитики], [срок]
- [ ] Иконка 1024×1024 (черновая — `mobile/assets/icon.png`, к релизу лучше нарисованная)
- [ ] Анкеты возрастного рейтинга (подсказки — в listing)
- [ ] Видео-превью по раскадровке (необязательно, но заметно поднимает установки)

**App Store Connect**
- [ ] Название, подзаголовок, ключевые слова, рекламный текст, описание — из `listing-*.md`, обе локализации
- [ ] Скриншоты `screens/ios/` (до 10 на язык), видео 886×1920
- [ ] App Privacy («Data Not Linked to You»: использование продукта, диагностика — если включена аналитика)
- [ ] Категория Games → Arcade

**Google Play Console**
- [ ] Краткое и полное описание, скриншоты `screens/play/` (2–8 на язык)
- [ ] Графика для витрины 1024×500 (feature graphic) — готова: `screens/play/feature-ru.png`, `feature-en.png`
- [ ] Data safety: собираются данные приложения (взаимодействие, диагностика), не связаны с пользователем, шифруются при передаче, можно запросить удаление
- [ ] Целевая аудитория и содержание: игра подходит детям — проверить требования программы Families, если отмечать возраст младше 13
